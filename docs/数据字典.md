# 日常记账理财管理系统——数据字典

> **数据库名称**：`smart_ledger`  
> **字符集**：utf8mb4  
> **排序规则**：utf8mb4_unicode_ci  
> **存储引擎**：InnoDB  

---

## 1. user 表（用户表）

| 字段名/列名 | 中文名 | 数据类型/长度 | 默认值/NULL | 取值含义（标注主码、外码） | 取值范围/约束或特殊要求 |
|-------------|--------|--------------|-------------|---------------------------|------------------------|
| user_id | 用户ID | INT | NOT NULL, AUTO_INCREMENT | 用户的唯一标识，主码 | 自增整数，从 1 开始 |
| username | 用户名 | VARCHAR(50) | NOT NULL | 用户登录名，全局唯一 | 最长 50 字符，UNIQUE 约束 |
| password | 密码 | VARCHAR(255) | NOT NULL | 用户登录密码的 bcrypt 哈希值 | 最长 255 字符，存储哈希而非明文 |
| register_time | 注册时间 | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 用户注册的日期时间 | 格式：YYYY-MM-DD HH:MM:SS |

---

## 2. category 表（收支分类表）

| 字段名/列名 | 中文名 | 数据类型/长度 | 默认值/NULL | 取值含义（标注主码、外码） | 取值范围/约束或特殊要求 |
|-------------|--------|--------------|-------------|---------------------------|------------------------|
| category_id | 分类ID | INT | NOT NULL, AUTO_INCREMENT | 分类的唯一标识，主码 | 自增整数，系统预设 1-9 |
| category_name | 分类名称 | VARCHAR(50) | NOT NULL | 收支分类的中文名称 | 预设值：餐饮、购物、娱乐、交通、学习、工资、奖学金、生活费、兼职收入 |
| type | 收支类型 | ENUM('income', 'expense') | NOT NULL | 标识该分类属于收入还是支出 | 仅允许 'income' 或 'expense' |

---

## 3. monthly_budget 表（月度预算表）

| 字段名/列名 | 中文名 | 数据类型/长度 | 默认值/NULL | 取值含义（标注主码、外码） | 取值范围/约束或特殊要求 |
|-------------|--------|--------------|-------------|---------------------------|------------------------|
| user_id | 用户ID | INT | NOT NULL | 预算所属用户，复合主码之一，外码（参照 user 表） | 必须存在于 user.user_id，ON DELETE CASCADE |
| year_month | 年月 | INT | NOT NULL | 预算对应的年月，复合主码之一 | 格式：YYYYMM（如 202606），CHECK 约束：BETWEEN 200001 AND 210012 |
| amount | 预算金额 | DECIMAL(10,2) | NOT NULL | 该月度的预算总额（元） | 精确到小数点后两位，必须大于 0 |

---

## 4. bill_record 表（账单记录表）

| 字段名/列名 | 中文名 | 数据类型/长度 | 默认值/NULL | 取值含义（标注主码、外码） | 取值范围/约束或特殊要求 |
|-------------|--------|--------------|-------------|---------------------------|------------------------|
| record_id | 记录ID | INT | NOT NULL, AUTO_INCREMENT | 账单记录的唯一标识，主码 | 自增整数 |
| amount | 金额 | DECIMAL(10,2) | NOT NULL | 该笔收支的金额（元） | 精确到小数点后两位，必须大于 0 |
| date | 日期 | DATE | NOT NULL | 该笔收支的发生日期 | 格式：YYYY-MM-DD，支持历史日期 |
| remark | 备注 | VARCHAR(255) | NULL | 该笔收支的文字备注说明 | 最长 255 字符，可选字段 |
| user_id | 用户ID | INT | NOT NULL | 该笔账单所属用户，外码（参照 user 表） | 必须存在于 user.user_id，ON DELETE CASCADE |
| category_id | 分类ID | INT | NOT NULL | 该笔账单所属分类，外码（参照 category 表） | 必须存在于 category.category_id，删除分类时 RESTRICT |

---

## 5. ai_report 表（AI 财务报告表）

| 字段名/列名 | 中文名 | 数据类型/长度 | 默认值/NULL | 取值含义（标注主码、外码） | 取值范围/约束或特殊要求 |
|-------------|--------|--------------|-------------|---------------------------|------------------------|
| report_id | 报告ID | INT | NOT NULL, AUTO_INCREMENT | 报告的唯一标识，主码 | 自增整数 |
| content | 报告内容 | TEXT | NOT NULL | AI 生成的 Markdown 格式财务分析报告全文 | 无长度限制（TEXT 类型），不可为空 |
| year_month | 年月 | INT | NOT NULL | 报告对应的年月 | 格式：YYYYMM（月度报告）或 YYYY00（年度报告，如 202500），CHECK 约束：BETWEEN 200001 AND 210012 |
| user_id | 用户ID | INT | NOT NULL | 报告所属用户，外码（参照 user 表） | 必须存在于 user.user_id，ON DELETE CASCADE |

---

## 6. 表关系汇总

| 子表 | 外码字段 | 参照父表 | 参照字段 | 删除策略 | 说明 |
|------|----------|----------|----------|----------|------|
| monthly_budget | user_id | user | user_id | CASCADE | 删除用户时级联删除其预算 |
| bill_record | user_id | user | user_id | CASCADE | 删除用户时级联删除其账单 |
| bill_record | category_id | category | category_id | RESTRICT | 分类下有账单时禁止删除分类 |
| ai_report | user_id | user | user_id | CASCADE | 删除用户时级联删除其报告 |
