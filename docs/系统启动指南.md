# 日常记账理财管理系统——启动指南

> **最后更新**：2026-06-06  
> **适用环境**：macOS / Linux  

---

## 1. 环境要求

| 依赖 | 版本要求 | 说明 |
|------|----------|------|
| Python | ≥ 3.10 | 后端运行环境 |
| Node.js | ≥ 18 | 前端运行环境 |
| MySQL | ≥ 8.0 | 数据库服务 |
| Git | 任意版本 | 代码管理 |

---

## 2. 项目初始化（首次运行）

### 2.1 克隆项目

```bash
git clone https://github.com/zylLucy/finance-management-system.git
cd finance-management-system
```

### 2.2 初始化数据库

```bash
# 登录 MySQL 并执行建表脚本
mysql -u root -p < database/initial_schema.sql

# 导入模拟数据（可选，用于测试）
mysql -u root -p smart_ledger < database/mock_data.sql
```

### 2.3 配置后端

```bash
cd backend

# 创建虚拟环境
python3 -m venv venv

# 激活虚拟环境
source venv/bin/activate

# 安装依赖
pip install fastapi uvicorn sqlalchemy pymysql bcrypt python-dotenv openai

# 创建配置文件
cp config.example.py config.py
# 编辑 config.py，填写数据库连接信息

# 创建大模型配置
cp .env.example .env
# 编辑 .env，填写 LLM_API_KEY 等大模型配置
```

### 2.4 配置前端

```bash
cd ../frontend

# 安装依赖
npm install
```

---

## 3. 启动系统

### 3.1 启动后端

```bash
cd backend
source venv/bin/activate
python main.py
```

后端启动后访问地址：`http://localhost:8000`

### 3.2 启动前端

```bash
cd frontend
npm run dev
```

前端启动后访问地址：`http://localhost:5173`

### 3.3 一键启动（推荐）

在项目根目录下：

```bash
# 终端 1：启动后端
cd backend && source venv/bin/activate && python main.py

# 终端 2：启动前端
cd frontend && npm run dev
```

## 6. 常见问题

### Q1：后端启动报 `ModuleNotFoundError`

确保已激活虚拟环境并安装了所有依赖：

```bash
source backend/venv/bin/activate
pip install fastapi uvicorn sqlalchemy pymysql bcrypt python-dotenv openai
```

### Q2：数据库连接失败

检查 `backend/config.py` 中的数据库配置是否正确，确保 MySQL 服务已启动：

```bash
# 检查 MySQL 状态
mysqladmin -u root -p status
```

### Q3：端口被占用

```bash
# 释放 8000 端口（后端）
lsof -ti:8000 | xargs kill -9

# 释放 5173 端口（前端）
lsof -ti:5173 | xargs kill -9
```

### Q4：AI 报告生成失败

检查 `backend/.env` 中的大模型配置：

```env
LLM_API_KEY=your_api_key_here
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-v4-flash
```

### Q5：前端页面空白

确保后端已启动，前端 Vite 开发服务器正常运行。检查浏览器控制台是否有跨域或网络错误。
